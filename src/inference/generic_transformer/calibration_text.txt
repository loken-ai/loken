fn merge_sorted(a: &[u32], b: &[u32]) -> Vec<u32> {
    let mut out = Vec::with_capacity(a.len() + b.len());
    let (mut i, mut j) = (0, 0);
    while i < a.len() && j < b.len() {
        if a[i] <= b[j] {
            out.push(a[i]);
            i += 1;
        } else {
            out.push(b[j]);
            j += 1;
        }
    }
    out.extend_from_slice(&a[i..]);
    out.extend_from_slice(&b[j..]);
    out
}

A cache keeps the entries a program asked for most recently, so that asking again is fast. When it
is full, the entry that was used longest ago makes room for the new one. The cost of a miss is the
time to fetch the entry from the slower store; the benefit of a hit is the time that fetch would
have taken. A cache pays for itself when the hit rate times the fetch time exceeds the time spent
looking entries up.

def moving_average(values, window):
    total = 0.0
    out = []
    for i, v in enumerate(values):
        total += v
        if i >= window:
            total -= values[i - window]
        out.append(total / min(i + 1, window))
    return out

Limits:

- **Prefill is compute-bound** in the delta-rule projections, convolution, scan and the wide mixers.
  The expert copy is hidden behind it.
- **The first 128 decoded tokens run while the expert cache learns.** A decode rate over fewer tokens understates the steady state.
- **The 512-expert file** holds 77 GB of experts against 56 GB of host memory in the scope measured, and that case is untried.
  Only 3 quarters of the memory the kernel still has free is page-locked.
  The rest copies through the driver's staging at a lower rate.
- **2 cards** under the cache plan cut the layers by link.
  The card on the slower link (x4 here) holds the layers it can hold whole.
  The other card holds the rest with a cache.
- The decode of a card with a cache is bound by the host launching its kernels 1 by 1, since the decode graph is off for these files.
- **Multi-token prediction** runs as a draft head that `loken draft-head` writes beside the model from the checkpoint's `mtp.*` tensors.
  The decode drafts with it only when `fidelity = "fast"` is set and the decode graph is recorded.
- **DeepSeek V4.1 native draft** is the DSpark head, the checkpoint's `mtp.*` tensors, read from the model file or a companion.
