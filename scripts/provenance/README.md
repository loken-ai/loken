# Provenance manifest

`manifest.tsv` - one row per file that still shares body lines with the reference checkouts
(named by `LOKEN_PROVENANCE_REFS`), plus a zero row for every CUDA translation unit: path, body-match %, body
lines matched, closest upstream file. Generated by the provenance script (exact-line,
body-only intersection); regenerate after any de-vendoring batch and commit alongside it.

`src/notice_gate.rs` reads this file: everything at or above the threshold there must hold a
row in NOTICE.md, and every NOTICE row must still be above the threshold - so NOTICE shrinks
as the measurement does, and cannot shrink ahead of it.
